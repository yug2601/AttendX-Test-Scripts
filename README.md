# AttendX Test Scripts

## Project Description
This repository contains sample automated test scripts
for the AttendX student attendance application.

## Files

1. test_login.py
   - Tests successful login.
   - Tests invalid password.
   - Tests empty username.

2. test_attendance.py
   - Tests marking a student present.
   - Tests marking a student absent.
   - Tests missing student ID.
   - Tests invalid attendance status.

## Prerequisites
- Python 3
- pytest

## Installation
Install pytest using:

    python -m pip install pytest

## Run Tests
Run all tests using:

    python -m pytest -v
